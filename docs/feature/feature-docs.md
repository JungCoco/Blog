### 만들어야 하는 기능

#### 1. 공개 영역

- 블로그 내 글 목록을 볼 수 있어야 함.
- 목록 내 특정 목록을 선택하면 상세 페이지로 넘어가야 함.
- 상세 페이지에는 해당 글의 모든 글이 보여야 함.
- 관리자는 로그인 할 수 있어야 함.

#### 2. 비공개 영역

- 에디터로 글을 작성할 수 있어야 함.
- 작성한 글을 저장할 수 있어야 함.
- 본인이 저장한 글 목록을 볼 수 있어야 함.
- 본인의 글에 공개/비공개 설정을 할 수 있어야 함.
- 본인의 글을 카테고리별로 볼 수 있어야 함.
