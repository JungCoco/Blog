### 레이아웃과 디자인 규격

##### 0. Colors: “겨울 브라이트/청량”톤
- 기본 배경색: #FFFFFF 100%
- 특정 섹션 배경 색: #F3F6FA 100%
- UI 기본 색상: #14213D 90%
- 메인 텍스트 색상: #1F2937 100%
- 글 제목 텍스트 색상: #0B1F3B 100%
- 글 서브 텍스트 색상: #334155 100%
- 글 본문 텍스트 색상: #1F2937 100%
- 글 서브 텍스트 색상: #64748B 100%

##### 1. Spacing
- 기준: **2px 스케일**(2의 배수)로 통일
- 적용 범위: padding / margin / gap(컴포넌트 간격) / section spacing / 페이지 여백
- 운영 원칙: 실사용은 **4px 단위(4, 8, 12, 16...)를 우선** 사용하고, 2px은 미세 조정(아이콘 정렬/라인 간격/좁은 컴포넌트)에만 제한적으로 사용
- 예외(허용): 1px(보더)

**Spacing scale (px)**
- 0, 2, 4, 6, 8, 10, 12, 14, 16, 20, 24, 32, 40, 48, 64, 80, 96

##### 2. Typography
- 단위 통일: `font-size`는 px, `line-height`는 px로 전부 명시
- 리듬 규칙: 본문/보조(13~20)는 넉넉하게, 헤딩(24+)은 타이트하게

##### 3. Font scale & Mapping (size / line-height)
- 13 / 20 : 카테고리·태그·메타·캡션·코드 스니펫
- 14 / 22 : 날짜를 나타내는 텍스트·댓글
- 15 / 24 : 메인 텍스트·섹션 내 글 타이틀 텍스트
- 16 / 26 : 
- 17 / 28 : 본문 텍스트·홈 목록 요약 텍스트
- 18 / 28
- 19 / 30
- 20 / 32 : 글 목록 타이틀
- 24 / 34 : 본문 내 머릿글
- 30 / 42 : 글 페이지 본문 헤드라인 타이틀
- 32 / 44 : 홈 섹션 헤드라인 타이틀
- 36 / 48 : 홈 배너 타이틀
- 48 / 60 : 글 페이지 메인 타이틀

##### 4. Font Weight
- Regular: 400
- Medium: 500
- Semibold: 600
- Bold: 700

##### 5. Radius (Shape)
- 목적: 컴포넌트의 “성격(단단함/부드러움)”을 결정하는 토큰. Spacing 스케일과 분리해서 운영.
- 원칙: **기본은 8px**, 큰 컴포넌트(카드/모달)는 12px 이상, 작은 컴포넌트(칩/뱃지)는 9999px(필) 또는 12px.

- **Radius scale (px)**
    - r0: 0
    - r4: 4
    - r8: 8  *(default)*
    - r12: 12
    - r16: 16
    - r999: 9999  *(pill/full)*
