# Design Concept

## One-liner

생각해둔 컨셉을 한 문장으로 고정하자면,

##### "나의 시행착오와 배운 점을 기록으로 남기고, 공유를 통해 피드백을 받아오는 기술 블로그"

가 기본 컨셉이다.

## Brand Tone & Manner

### keyworkd

- **미니멀:** 최소 주의, 정보 위계가 최우선이다.
- **가독성:** 대비, 간격, 정렬이 일관되고 명확하여 빠르게 읽히고 스캔되어야 한다.
- **깔끔함:** 과한 효과 없이 아웃라인과 타이포그래피 중심으로 정돈된 느낌을 만들어야 한다.
- **조용함:** 시각적인 소음은 최대한 줄이면서 애니메이션, 그림자 등은 과하지 않게 사용해야 한다.
- **사용성:** 사용성은 매우 스무스해야 한다.

### Tone

1. 블로그 포지션은 **문서형 + 프로덕트형**을 생각하고 있다. 개인적인 에세이나 일기장처럼 사용하는 게 아닌 **'기술적 기록'**에만 제한할 생각이기에 이렇게 정했다. 반복학습 또한 목적에 두고 있다.

- 시행착오 기록
- 경험 기록
- 의문/지식 기록
  &nbsp;

1. 포인트 컬러는 { ??? }

- 이번 블로그는 말 그대로 '나'를 기록해두고 싶은 거라 컬러는 나와 최대한 잘 어울리는 컬러로 선정하여 사용하고 싶었다.
- 그렇게 진단받은 퍼스널 컬러는 '봄웜 라이트'였으니 선택한 컬러는 { ??? } 이다.
- 그렇게 나온 컬러가 { ??? } 색상이다.
  &nbsp;

1. 톤을 유지하는 규칙은 이렇게 정했다.

- 기본 베이스는 #FFFFFF, #000000으로 화이트/블랙으로 잡는다.
- 포인트 컬러는 버튼이나 토글 등 UI 요소에만 사용한다.
- 텍스트 컬러는 검은색, 회색 계열의 색상 코드로 메인 텍스트 색상인 { ??? }을 사용하고 서브 텍스트 색상은 { ??? }으로 한다.
- 제목-요약-메타의 위계 질서가 톤의 핵심이다.

### Layout

아직 구체적인 레이아웃과 요소는 생각하지 않았지만 차차 생각이 나고 결정하는데 문서를 업데이트 할 것이다.

1. 우선 랜딩 페이지까지 만들고 다음 페이지를 생각할 것 (생각이 안 나요..)

- 레이아웃 규격과 기본적인 디자인 규격은 잡고 시작할 것. (radius, 너비, gap, 배수 단위? 등등)
  - 랜딩 페이지 UI작업을 우선적으로 한 후 글 페이지 디자인 시작

#### Default

- ## 모든 페이지에는 내비게이션바가 보여야 한다.
  - 내비게이션바의 높이는 60px(사용할 때는 rem으로)로 잡는다.
  - 바 왼쪽에는 블로그 네임과 로고가 들어갈 예정이고, 오른쪽에는 3~4개의 메뉴 그리고 로그인 버튼이 들어갈 것이다.
  - 로그인 버튼은 추후 관리자 페이지 사용을 위함이다.
- 모든 페이지에는 footer가 존재해야 한다.

#### 랜딩 페이지

- 블로그 랜딩 페이지에는 상단에 배너 섹션이 존재한다.
  - 배너 섹션에는 인기 글 or 최신 글 등 특정 기준을 세워서 들어가게 할 것이다.
- 배너 다음에는 바로 최신글 목록이 나온다.
  - 여기서는 전체 글이 모두 보이게 할 것이며, 페이지네이션 방식으로 구현할 것이다.
  - 한 페이지당 5~6개의 글이 렌더링되게 할 것이다.
- 최신 글 목록은 column방식이 아니라 사이드 메뉴와 row방식으로 만들 것이다.
  - 배너 하단 왼쪽(너비-2/3 정도)은 최신 글 목록이 차지한다.
  - 배너 하단 오른쪽 나머지 부분은 사이드 메뉴가 차지한다.
  - 사이드 메뉴는 인기글 or 댓글 or 업데이트 노트 등을 생각하고 있다.
